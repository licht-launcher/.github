## Your game, organized

- **Separate instances** — keep game folders, memory settings, and Java settings independent.
- **Vanilla or modded** — install Fabric, Quilt, Forge, or NeoForge, and import Modrinth or CurseForge modpacks.
- **Windows and Linux** — choose an installer, AppImage, Debian package, or portable binary from our releases.
- **Open development** — explore the source, suggest features, and help shape the launcher on GitHub.

Built with **Tauri v2**, **React**, **TypeScript**, and **Rust**.
